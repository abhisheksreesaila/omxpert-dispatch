Night 6: three sets of tricks, one engine

Qwen3.8-Flash-Next (Qwen 4 preview architecture, 111 GB at 4-bit) on 2× RTX 3090 + 64 GB RAM. Every number below was measured on this box (results/night6).

Before and after, as data flow

Before: llama.cpp's fit (range partitioning by layer)
GPUs: layers 1–24, all 512 experts each (37.7 GB), including the ones your work never picks
RAM (page cache): layers 25–48, all experts (39 GB)
CPU: computes every pick of layers 25–48: half of the 480 picks per token, 32 of 49 ms
GPU and CPU take turns: the token waits for both
After: your profile tiers the experts (hot/cold storage, parallel query)
GPUs: the experts your chat history uses most, from all 48 layers (36,500 MiB, 51% of all experts), 94% of held-out chat picks
RAM: only the experts not in VRAM (exclusive tiers, no double copies)
CPU: the few cold picks, computed while the GPUs compute the hot ones
prompt batches run each layer on the GPU that owns its pins
